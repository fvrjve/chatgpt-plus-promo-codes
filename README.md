## ChatGPT Plus 优惠码从哪来：正规来源只有一种

按照官方机制，OpenAI 会不定期和合作方——比如当地运营商、银行、各类 App 的会员体系——做联合活动。码通过对方的短信或 App 内专属链接发到符合条件的用户手里，发放节奏、地区和数量完全取决于合作方。官方这边没有一个“输入优惠码领折扣”的公共入口。

兑换流程，按官方口径是这样走的：

1. 从合作方拿到专属码，通常在对方 App、会员权益页，或者一条短信里；
2. 点对方提供的专属兑换链接，登录或注册 ChatGPT 账号；
3. 资格校验通过后，页面会提示优惠生效：要么跳到结账页（折扣自动套用），要么直接生效、无需付款；
4. 如果到了结账页，先核对价格——试用活动应显示 $0.00，折扣活动应显示折后价。价格对不上就停手，截图后联系发码方或官方支持；
5. 直接生效型的，收到确认后进设置里核实一下订阅档位是否已经换成 Plus。

第 4 步是官方文档里反复强调的：**结账页价格不对，就不要完成支付**。
